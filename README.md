# Project01_Prototype

스트레스 해소 게임 「제자리」(가제)의 **시험용 프로토타입**입니다. 도형으로만 만든 버전이며, 손맛·리듬·1분 흐름을 시험하는 용도입니다.

- 플레이 주소: https://qkrwogns.github.io/Project01_Prototype/
  - 주소 뒤에 다른 글자가 붙으면 "There isn't a GitHub Pages site here"가 뜹니다. 링크는 앞뒤에 글자 없이 한 줄로 보내 주세요.
- 기획서와 작업 보고서는 별도의 비공개 저장소에서 관리합니다.

## 해 보는 방법

1. 휴대폰 브라우저로 위 주소를 엽니다. 세로로 들고 한 손 엄지로 합니다.
   - 화면은 지하철 한 칸을 위에서 본 모습입니다. 위아래가 칸의 옆벽이고, 아래쪽 문이 승강장 쪽입니다.
2. **시작**을 누르면 바로 한 판이 시작됩니다. 문은 처음부터 열려 있습니다.
3. **순서는 자유**입니다. 눈에 보이는 대로 정리하세요.
   - 통로를 막은 승객(가방을 뒤로 멘 사람, 길을 막고 선 사람): **톡**
   - 문 앞에 모인 사람들: **양옆으로 쓱**
   - 승강장에 뭉친 사람들: **아래로 쓱** (문 양옆에 두 줄로 섬)
4. 문이 닫히기 전에 모두 정리하면 성공입니다. 한 판은 약 1분입니다.
5. 끝나면 답답한 정도와 느낌을 고르고(선택), **다시 하기** 또는 **그만하기**를 누릅니다.

- **설정 · 숫자 조정**: 톡 대상 수, 정리 시간, 진동 켜기/끄기를 바꿀 수 있습니다.
- **기록 보기**: 판마다 결과와 자가 평가가 휴대폰에만 저장됩니다. "기록 복사하기"로 복사해 Claude에게 붙여 넣으면 분석할 수 있습니다.

## 알아 둘 점

- 아이폰 브라우저는 웹 표준 진동을 지원하지 않아, 스위치를 누를 때 나는 기본 진동을 빌려 씁니다. 진동이 약하거나 없을 수 있습니다. 진동 종류는 이후 앱인토스 테스트 환경에서 고릅니다.
- 점수, 로그인, 리더보드, 광고, 소리는 이 시험 버전에 없습니다.
- 플레이 전 답답한 정도는 고르는 화면 없이 5로 고정해 두었습니다. 끝난 뒤의 답답한 정도·느낌은 시험 기록용(선택)이며 출시 버전에는 넣지 않습니다.
