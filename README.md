# Project01_Prototype

스트레스 해소 게임 「제자리」(가제)의 **시험용 프로토타입**입니다. 도형으로만 만든 버전이며, 손맛·리듬·1분 흐름을 시험하는 용도입니다.

- 플레이 주소: https://qkrwogns.github.io/Project01_Prototype/ (GitHub Pages를 켠 뒤 열림)
- 기획서와 작업 보고서는 별도의 비공개 저장소에서 관리합니다.

## 해 보는 방법

1. 휴대폰 브라우저로 위 주소를 엽니다. 세로로 들고 한 손 엄지로 합니다.
2. **시작** → "지금 답답한 정도"를 고르거나 건너뜁니다.
3. 통로를 막은 승객(가방을 뒤로 멘 사람, 길을 막고 선 사람)을 **톡** 누릅니다.
4. 문이 열리면 문 앞 사람들을 **양옆으로 쓱**, 승강장 사람들을 **아래로 쓱** 정리합니다.
5. 문이 닫히기 전에 모두 정리하면 성공입니다. 한 판은 약 1분입니다.
6. 끝나면 답답한 정도와 느낌을 고르고(선택), **다시 하기** 또는 **그만하기**를 누릅니다.

- **설정 · 숫자 조정**: 톡 대상 수, 구간 길이, 진동 켜기/끄기를 바꿀 수 있습니다.
- **기록 보기**: 판마다 결과와 자가 평가가 휴대폰에만 저장됩니다. "기록 복사하기"로 복사해 Claude에게 붙여 넣으면 분석할 수 있습니다.

## 알아 둘 점

- 아이폰 브라우저는 웹 표준 진동을 지원하지 않아, 스위치를 누를 때 나는 기본 진동을 빌려 씁니다. 진동이 약하거나 없을 수 있습니다. 진동 종류는 이후 앱인토스 테스트 환경에서 고릅니다.
- 점수, 로그인, 리더보드, 광고, 소리는 이 시험 버전에 없습니다.
- 플레이 전후 0~10점 자가 평가는 시험용이며 출시 버전에는 넣지 않습니다.
